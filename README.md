# Connections Coordinator

An unofficial brainstorming tool for the [NY Times Connections](https://www.nytimes.com/games/connections) puzzle.

> This project is not affiliated with The New York Times.

## Features

- Drag and drop tiles to rearrange freely
- Paint tiles to brainstorm groups
- Sort tiles by color, or shuffle

## Usage

Open `index.html` in any modern browser. No build step or server required.

Enter the 16 puzzle tiles (one per line or comma-separated), then click **Load board**.
